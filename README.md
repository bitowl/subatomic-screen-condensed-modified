# Subatomic Screen Condensed (modified)

This is a modified version of the [Subatomic Screen Condensed](https://www.dafont.com/subatomic-screen.font) font by [Kevin Meinert](https://www.subatomicglue.com/about).
A few glyphs have been added and a few were modified.

The source file can be edited in [PixelForge](https://www.pixel-forge.com) and is available at [subatomic-sc-modified.pxf](./subatomic-sc-modified.pxf).
The resulting ttf file is available at [atomicsc-modified.ttf](./atomicsc-modified.ttf).

You can find the README of the original font at [readme.txt](./readme.txt).
